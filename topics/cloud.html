Cloud fundamentals

Renting computers by the second.

Lesson

Cloud providers (AWS, Azure, Google Cloud) rent you compute, storage and networking on demand. You pay for what you use and can scale up or down in minutes.

The big building blocks: virtual machines (EC2), object storage (S3), managed databases (RDS), and networking (VPCs, subnets, security groups). Regions and availability zones let you spread your app across data centres for resilience.

Service models: IaaS gives you machines, PaaS gives you a platform to run code, SaaS gives you finished software.

Key points

  • Compute, storage, network
  • Regions & availability zones
  • IaaS / PaaS / SaaS
  • Pay as you go

Practise in the terminal

This is a simulated Linux machine with real commands: files, git, docker, kubectl, terraform, aws and more. Type a command and press Enter, or click the suggestions below in order. Nothing touches a real computer.

  • aws sts get-caller-identity Who am I in AWS?
  • aws s3 ls List buckets
  • aws s3 ls s3://shipyard-assets Files in a bucket
  • aws s3 mb s3://tejus-demo-bucket Create a bucket
  • aws s3 cp report.csv s3://tejus-demo-bucket/ Upload a file
  • aws s3 ls s3://tejus-demo-bucket Check it arrived
  • aws ec2 describe-instances --output table List virtual machines
  • aws ec2 start-instances --instance-ids i-0f9e8d7c6b5a40312 Start the stopped one
  • aws ec2 run-instances --image-id ami-0dee22c13ea7a9a67 --instance-type t3.micro Launch a new VM
  • aws configure list Current region and keys
